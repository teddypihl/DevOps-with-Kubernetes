
## DBaaS vs DIY

DBaaS is easier to setup and maintain since google does a lot of the harder tasks but the downside is that this makes it not free.

When running DIY PostgreSQL we don’t need to pay for anything but we are the people doing the heavy lifting configuring almost everything.

Another benefit of using DBaaS is their secure cloud backups which do not exist for us running PostgreSQL locally since our backups must handle security and testing ourselves.
